# Shaik Rahim – Digital Marketing Portfolio

Static multi-page portfolio built with HTML5, CSS3 and vanilla JavaScript.

## Run locally
Open `index.html` in your browser, or use the VS Code Live Server extension.

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of the repository `shaikrahimdigital.github.io`.
2. In GitHub, open Settings → Pages.
3. Choose Deploy from a branch, branch `main`, folder `/ (root)`, then Save.
4. Wait for GitHub Pages to publish the site.

## Add your assets
- Logo: `assets/images/brand/`
- Profile photo: `assets/images/profile/`
- Project screenshots: `assets/images/projects/`
- Social creatives: `assets/images/creatives/social-media/`
- Ad creatives: `assets/images/creatives/ads/`
- Banners: `assets/images/creatives/banners/`
- Brochures: `assets/images/creatives/brochures/`
- Certificates: `assets/images/certificates/`
- Videos: `assets/videos/reels/` and `assets/videos/campaigns/`
- Resume PDF: `assets/documents/resume.pdf`

Replace the clearly labelled content slots with approved assets and verified project information. No campaign performance figures are attributed to specific projects unless evidence is added.
